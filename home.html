How Kaihōua works

Kaihōua fetches prices directly from the same internal JSON APIs that the supermarket websites use to load their own product pages.

Woolworths NZ exposes endpoints like:
woolworths.co.nz/apis/ui/Search/products?searchTerm=milk
which return structured JSON with prices, specials, unit prices and more.

Pak'nSave & New World (Foodstuffs) use:
shop.paknsave.co.nz/CommonApi/Store/GetProducts
returning similar JSON product data.

Because these APIs are what the supermarket's own websites use, the data is always up-to-date. A CORS proxy (corsproxy.io) is used to allow browser-based access.

Pricing data is for informational purposes only. Store locations affect prices — this app uses Wellington-area stores by default. The Commerce Commission recommends supermarkets cooperate with price comparison services.
